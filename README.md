# 数学分析复习本

这是独立于高代网站的数学分析复习项目，正在制作中。计划覆盖华师大第六版上册第二章至第五章；目前只有 2.1 例 1—9、习题 2.1 第 1—10 题、2.2 例 1—6、习题 2.2 第 1—2 题和习题 4.1 第 9 题完成首轮整理。第四章其余部分及第五章题目清单尚待逐页核对，其他题目、章节导图和全面核验尚未完成。

本机访问：双击“启动网站”命令文件，保持窗口打开，在浏览器访问 http://127.0.0.1:47656/。备用方式：在 PowerShell 中运行本目录的“启动网站.ps1”。默认只监听本机。

“⭐”收藏、单题复习标记与小节已复习状态保存在当前浏览器的本地存储；更换浏览器、网址或设备不会自动同步。题目清单.md 和 data/inventory.json 记录已清点范围的题号、印刷页、PDF 页及答案资料对应状态。修改清单时，先修改 tools/build_inventory.py，再运行它生成清单和站内数据。

已整理内容并不等同于全书全部数学证明已独立复核；见 TASK_PROGRESS.md。数学公式使用本地 KaTeX，许可证见 dist/katex/LICENSE。
