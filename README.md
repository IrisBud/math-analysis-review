网站提供独立折叠的题解、思路引导和练习，考试重点标记及凑 1、渐近线、连续性求参数、Stolz 定理四个专题。前三个专题各五道自编题；Stolz 专题有一道期中原题和四道自编题。第二、三章及 §4.1 的导图节点已检查选中和跳题，其他范围仍需核验。“⭐”收藏、小节已复习和单题复习标记只保存在当前浏览器；本机地址与在线地址互不自动同步。

此仓库只包含静态运行文件和 KaTeX 许可，不包含教材或参考答案 PDF。若本地克隆，可在仓库目录运行 python -m http.server 47656，然后访问 http://127.0.0.1:47656/。
